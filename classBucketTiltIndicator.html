Detailed Description

BucketTiltIndicator

Vector-drawn bucket tilt gauge. Replaces the rotated PNG indicator (newbucket.png + rotate_image()) with a self-drawing widget that:

  • renders a proper bucket silhouette at the current tilt
  • draws a horizon reference line and a graduated arc with tick marks
  • colour-grades the warning ring (green -> amber -> red) instead of a binary white/red flash
  • shows a large numeric degree readout below the gauge
  • flags the load state (CRADLED / LEVEL / DUMPING) so the operator can tell at a glance whether material would spill

Drop-in replacement for the old Gtk::Image-based indicator. The widget owns its own redraw; the call site just does indicator->set_angle(deg).

Default warning thresholds match the talos.urdf Bucket_Joint limits (-0.45 rad -> 2.2 rad, i.e. ~ -26 deg .. 126 deg) with a small margin. Override with set_warning_angles() if you want different bounds.
